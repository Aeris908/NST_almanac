# Проверка NST Almanac — 10–11 ноября 2026

Проверены структура репозитория, сборка, путь данных и редактирования, документация,
синтаксис Python/JavaScript, JSON и локальные ссылки пяти страниц. На начало проверки
в git было 280 файлов: 168 Python, 29 JSON, 21 CSV, 16 HTML, 13 JavaScript,
13 Markdown, 11 CSS и вспомогательные файлы.

## Структура и поток данных

| Часть | Назначение |
|---|---|
| `collectors/`, корневые JSON, `data/`, `special_tournaments/` | Сбор и сохранённые источники матчей, комментариев, таблиц и решений |
| `db/schema.sql`, `build_db.py`, `import_stores.py`, `import_live.py` | Схема и импорт в локальную `data/nst.db` |
| `db/store.py`, `pg.py`, `sync.py` | Подключение SQLite/Postgres, адаптер SQL, перенос срезов |
| `db/edit.py`, `api.py`, `serve.py`, `api/handler.py` | Операции правки, журнал, предпросмотр и HTTP API |
| `portal/` | Читатели базы, нормализация имён, Elo сайта, профили, сезоны и payload страниц |
| `templates/`, стили и клиентские скрипты | Представление данных; редактор встроен в `soccer.html?edit=1` |
| `build_all.py`, `build_*.py`, `scan_audio.py` | Общая сборка пяти страниц и аудиоманифестов |
| `deploy/` | Копии готовых страниц и ресурсов для статического хостинга |
| `tests/` | Проверки импорта, модели, правок, транспорта и генераторов |
| `archive/` | Прежние генераторы, диагностические скрипты и версия каталога в виде альбома |
| `docs/`, `HANDOVER-*.md`, `README.md` | Документация; датированные планы и передачи сохраняют исторический контекст |

Обычная сборка обновляет базу из носителей. `--from-store` сохраняет существующий срез
и пересчитывает страницы. Статическая публикация через `deploy/` содержит страницы;
серверный редактор требует отдельного API или Vercel с конфигурацией из корня проекта.

## Исправлено

1. **Отсутствующая команда `pull`.** Документация предлагала её запуск, но CLI и функция
   отсутствовали. Теперь все 14 таблиц переносятся из согласованного снимка Postgres в готовую
   локальную базу одной транзакцией. Ошибки чтения и внешних ключей откатывают замену целиком.
2. **Неатомарный `push`.** Ранний `commit` фиксировал очистку сервера до переноса строк.
   Очистка, вставка, восстановление внешних ключей и последовательностей теперь составляют
   одну транзакцию; локальный источник также читается из одного снимка.
3. **Устаревшие данные предпросмотра Postgres.** Вместо серверных строк использовалась
   SQLite-база последней сборки. Теперь локальная копия даёт схему, а строки берутся с сервера.
4. **Вставка JSON в HTML.** Футбол, цитаты и аватары используют `json_for_script`, чтобы
   `</script>` внутри данных не завершал HTML-элемент. Адрес API экранируется как HTML-атрибут.
5. **Зависимость обычных тестов от внешней сети.** Живая сверка Postgres вынесена в явно
   включаемый режим `NST_RUN_LIVE_TESTS=1`, маркер `live`. Количества сравниваются с текущей
   локальной базой вместо жёстко заданных 402/2990.
6. **Документация.** Обновлены схема проекта и шаги сборки, переменные окружения, описание
   серверной записи и предпросмотра, правила запуска сборщиков данных, инструкция GitHub Pages.
   Убрана неподтверждённая MIT-плашка: файла лицензии нет. Отмечены недоступные в репозитории
   исследовательские `scratch/`-скрипты и исторический статус планов. Исправлены ссылки на
   отсутствующий `editor.html`, описание дизайна каталога и ошибочное утверждение о приватности
   отслеживаемых документов. Уточнено различие Elo сайта и отдельного аналитического дашборда;
   в описании дашборда исправлены опечатка и вес поражения в овертайме/по буллитам.

Добавлены восемь проверок переноса, отката, серверного предпросмотра и безопасного JSON.
Пересобраны `soccer.html`, `quotes.html` и их копии в `deploy/`.

## Границы проверки

Первый прогон включил живую сверку из-за настроенного URL Postgres: 325 тестов прошли,
один завершился ошибкой DNS облачного хоста. Поэтому текущая синхронность с Neon и поведение
боевого Vercel не подтверждены. Переносы проверены локальными тестами с подменой серверного
соединения; они не заменяют интеграционный прогон с Postgres.

Внешние исторические источники не перечитывались в интернете; спорные результаты матчей
не менялись. Существующие 25 задач лороведа сохраняются. `sync.py status` проверяет числа
строк, а не полное равенство содержимого. Визуальная проверка браузером не проводилась.
Данные облачной базы, публикация и удалённый репозиторий не изменялись.
