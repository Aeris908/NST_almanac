# Страница каталога игроков — дизайн

Дата: 2026-11-09. Статус: историческая спецификация первой версии.
Альбом заменён каталогом с фильтрами и досье; прежняя версия сохранена в
`archive/yearbook-players/`. Актуальная реализация — `players.js`, `players.css` и
`templates/players_page.html`; правила оформления — `docs/design-system.md`.
Документ отслеживается в git и при `vercel.json outputDirectory: "."` считается публичным.

## Цель и контекст

Новая самостоятельная страница `players.html` — каталог игроков сообщества NST по всем
дисциплинам. Данные уже собирает модуль `portal/players_dataset.py` (#94, чистый архив:
без демо-записей и дублей). Страница — **плейсхолдер первой версии** в облике «школьный
выпускной альбом»: реальные игроки, простые карточки, структура, удобная для правки.
Существующие страницы (soccer/quotes) не меняются; ссылка только с лендинг-хаба.

## Принятые решения (из диалога с владельцем)

- Форма: сетка карточек; модальная анкета — **позже** (вне этого объёма).
- Навигация: ссылка **только** с лендинг-хаба (`index.html`); шапки soccer/quotes не трогаем.
- Фильтры (дисциплина/статус) и поиск — **позже** (вне этого объёма).
- Стиль: страница **уникальна**, не привязана к `soccer.css` («каждая страница будет
  уникальна»). Собственный CSS, легко редактировать.
- Облик сейчас: **плейсхолдер «школьный альбом»** с реальными данными каталога.

## Архитектура и файлы

Самодостаточная страница по образцу `build_quotes_page.py` / `build_landing_page.py`:

| Файл | Ответственность |
|---|---|
| `templates/players_page.html` | шаблон: голова (свои шрифты, `audio-player.css`), обложка-заголовок, контейнер сетки, подвал, хвост скриптов (`const PLAYERS = @@PLAYERS_JSON@@`, `players.js`, `audio/playlist-manifest.js`, `audio-player.js`). `body data-discipline="players"`. |
| `players.css` | собственный стиль альбома; чистые секции с русскими комментариями (токены, обложка, сетка, карточка-фото, подвал). Не линкует `soccer.css`. |
| `players.js` | рендер сетки из `PLAYERS.players`; минимум логики, без фильтров/модалки в этой версии. |
| `build_players_page.py` | зовёт `build_players_dataset(store.DB_PATH)`, рендерит шаблон через `portal/templates.render` (токен `@@PLAYERS_JSON@@`), пишет `players.html`. Печатает счётчики (игроков, дисциплин). |
| `build_all.py` | новый шаг в `BUILDERS` последним (после сборки landing); `players.html` в `PAGES`; `players.js`, `players.css` в `ASSETS`. |
| `templates/landing_page.html` | одна ссылка `👤 Каталог игроков` в `.header-actions` (идиома `.nav-btn-link`, строки ~424–428). Больше ничего в существующих страницах не меняется. |

Рендер — `portal/templates.py: render` (замена `@@TOKEN@@`, бросает KeyError на оставшийся
маркер): лишних маркеров в шаблоне быть не должно.

## Поток данных

`build_players_dataset` (читает базу через шлюз `db/store.py`, исключает `source='demo'`
и `duplicate_of`) → словарь `{stats, disciplines, players}` → JSON встроен в `players.html`
как `const PLAYERS` → `players.js` рисует карточки. Поля карточки игрока, используемые
плейсхолдером: `nick`, `avatar`, `status_badge`, `is_active`, `is_hall_of_famer`,
`disciplines` (slug/name/icon), `featured_quote`, `career.wins`, `career.matches`.
Добавление игроков происходит автоматически при пересборке — править данные вручную не нужно.

## Визуальный язык «школьный альбом»

Намеренно другой облик, чем тёмное ретро soccer (страница уникальна), но цельный и аккуратный:

- **Фон:** тёплая бумажная страница (кремовый, напр. `#f4ecd8`), лёгкая текстура бумаги
  (CSS-градиенты, без внешних картинок).
- **Обложка-заголовок:** «Выпускной альбом NST», годы `2015–2026`, подзаголовок сообщества;
  заголовочный шрифт с кириллицей (напр. `Playfair Display`, fallback serif).
- **Карточка-«фотография»:** аватар в рамке (как фото в альбоме, лёгкий поворот/уголки),
  имя рукописным кириллическим шрифтом (напр. `Marck Script`, fallback cursive), краткий
  caption: дисциплина(ы) + статус, цитата при наличии, победы карьеры моношрифтом.
- **Сетка:** адаптивная (`auto-fill minmax`), карточки одной высоты.
- **Шрифты:** Google Fonts с кириллическим сабсетом — `Playfair Display` (обложка),
  `Marck Script` (имена), `Rubik` (текст, уже используется сайтом), моно для чисел.
  Fallback обязательно: cursive/serif/sans-serif. Наличие кириллицы проверить при реализации.
- **Подвал:** в общей идиоме сайта (ссылки на хаб/сообщество), но в палитре альбома.

## Тесты и проверка

- **TDD:** тест сборки страницы пишется первым (красный): `build_players_page` рендерит
  `players.html` без оставшихся `@@…@@`, встроенный `const PLAYERS` парсится, содержит
  `players`/`stats`/`disciplines`, число карточек > 0, демо-игроки не дают демо-дисциплин.
  Образец офлайн-фикстуры — `tests/test_players_dataset.py` (копия базы, `source_db`).
- Полный `pytest` (зелёный), `ruff check` по новым файлам (паритет/чисто), `db/validate.py`.
- `ruff format` не запускать (рукописный стиль проекта).
- Страница открывается локально (`python -m http.server`) и проверяется в браузере через
  DOM (`evaluate_script`): сетка отрисована, имена/аватары на месте, ссылка с хаба ведёт.
- Аудио-дека: `players.html` не совпадает ни с одним музыкальным ключом → fallback на
  hub-плейлист (`audio-player.js: detectDiscipline`); поведение не ломается.
- Сборка: `python build_all.py --from-store` (страница не требует перегенерации базы);
  `players.html` и ассеты попадают в `deploy/`.
