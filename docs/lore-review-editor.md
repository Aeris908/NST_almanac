# Редактирование задач командного архива

В кабинете лороведа выберите «Командный архив». После входа очередь перечитывается с сервера.

Ввод автоматически сохраняется в черновик этого браузера для каждой задачи. Поиск,
переключение фильтров и перезагрузка страницы не удаляют черновик. Откройте задачу повторно,
чтобы продолжить. Черновик не синхронизируется между устройствами; после восстановления
сверьте его с актуальным источником и выполните предпросмотр. При уходе с открытой
изменённой формой браузер предупредит о незавершённой работе. «Сбросить черновик» требует
подтверждения; после успешной записи черновик удаляется.

На широком экране источник находится рядом с формой. На узком экране кнопки «Источник»
и «Редактор» переключают области без удаления полей и позиции прокрутки текста.

1. Откройте источник и текст отчёта.
2. Нажмите «Разобрать отчёт и добавить игры» либо «Редактировать игры и вынести вердикт».
3. Для нового отчёта выберите турнир. Укажите лигу/группу, тур и стадию.
4. Укажите четыре ника в блоке «Составы отчёта». Подсказки ищут часть ника и алиасы без
   учёта регистра. Выберите вариант мышью либо стрелками и Enter: ввод сам не заменяется.
   Сервер отклонит неизвестный ник и не создаст игрока из опечатки.
   Новые игры используют общий состав; составы существующих игр сохраняются отдельно.
   «Применить состав ко всем играм» меняет их только по явному нажатию.
   Каждая строка — отдельная игра: укажите голы, результат и при необходимости буллиты.
   «Поменять пары и счёт» одновременно разворачивает стороны и результаты.
   «Изменить игроков этой игры» открывает отдельный состав для выбранной строки.
   «Добавить игру» создаёт ещё одну строку; «Убрать из этого решения» убирает строку только из
   текущего пакета правок и не удаляет существующую игру из базы.
5. Напишите обоснование. Если данные менять не нужно, выберите подтверждение без изменений.
   Если это дубль, цитата или неверный отчёт, выберите отклонение.
6. Нажмите «Предпросмотр решения», проверьте составы, счета и изменения общих показателей.
   Только после успешного предпросмотра доступно «Сохранить решение». Любое изменение полей
   требует нового предпросмотра.

Игры и вердикт задачи сохраняются одной транзакцией и одной операцией журнала. Ошибка в одной
строке откатывает весь пакет. Повторное решение закрытой задачи отклоняется. Источники
прикрепляются к играм; ручные правки защищены от обычного переимпорта. Обоснование и вердикт
сохраняются при обновлении носителей. «Откатить последнее изменение» отменяет весь пакет
вместе с закрытием задачи. Возможен откат конкретной операции по её метке через API/CLI.

Для существующего отчёта форма показывает все восстановленные игры этого отчёта с их ID,
составами и счетами. Турнир существующих игр здесь не переносится; его выбор заблокирован.
Голы и счёт буллитов задаются отдельно, чтобы победа после ничьей не превратилась в ничью.

Сохранение в базе не публикует статические страницы автоматически: обновление публичной
витрины требует штатной сборки и публикации.
Статус публикации сравнивает отпечаток данных открытой версии с сервером после входа.
Изменения ников и закрытие задач также учитываются, даже если счёт не менялся.

Очередь фильтруется по турниру и состоянию: без игр, требует уточнения, есть черновик.
После записи доступна кнопка «Следующая задача». Решённые в текущей сессии задачи исключаются
из рабочего списка. Журнал группирует все записи одного решения, показывает обоснование и
позволяет отменить выбранное решение целиком. Сервер запрещает такой откат, если те же строки
или матчи были изменены позднее; сначала нужно отменить более позднее решение.

Обычные карточки очереди также сохраняют счёт, стадию, тип результата и обоснование одной
операцией с закрытием задачи. Для ничьей с победой по буллитам нужны отдельные результаты
буллитов. Сохранение доступно после предпросмотра; изменение полей требует нового предпросмотра.
Импорт обычной очереди обновляет существующие задачи по источнику, сохраняя их ID,
вердикты и обоснования. Это сохраняет связь черновиков и журнала с задачей при пересборке.

Проверки: создание, изменение, подтверждение, отказ, повторное решение, предпросмотр,
атомарный откат при ошибке во второй игре и полный undo. Браузерный сценарий создания и
закрытия задачи выполнен на отдельной SQLite-копии через настоящий HTTP API.
