# Улучшения навигации и редактора — 12 ноября 2026

Сохранён визуальный язык футбольного портала: тёмный фон, золотые и голубые акценты,
существующая типографика. Фоны дисциплин не унифицированы.

* «Редактор» в шапке включает карандаши без ручного изменения адреса, сохраняя раздел и поиск.
* Из кабинета лороведа есть прямой переход «Редактор матчей».
* Токен, запомненный кабинетом, используется и в редакторе футбола. Дополнительных прав
  это не даёт: каждую запись по-прежнему проверяет API. Токен не передаётся в URL.
* «Скрыть» убирает панель и отключает перехват кликов по матчам; повторный вход доступен
  через шапку. Раньше скрывались только визуальные подсказки, а обработчик оставался активным.
* Панель и окно правки располагаются над аудиоплеером с учётом фактической высоты панели.
  На телефоне вместо горизонтального ряда кнопок используется меню действий.
* `/` фокусирует поиск в рейтинге, карточках игроков и очереди; при вводе в поле не перехватывается.
  Добавлены ссылка пропуска к содержимому, видимый фокус и подпись поля токена.
* Общая SVG-иконка вкладки для пяти страниц; мобильная надпись GOAL 3 больше не переносится.

Выявлено: на сервере появились реальные решения лороведа, но обычная сборка генерировала
страницы из импортного архива. На Vercel после подготовки схемы и до генерации страниц
теперь выполняется согласованное чтение Postgres через db/sync.py pull. Боевая база
не изменяется сборкой. Ошибка pull прерывает публикацию. Локальный from-store не заменяется.
Проверки порядка шагов и отказа при недоступном снимке: tests/test_hosted_build.py.

Проверено браузером: вход/скрытие/повторный вход, сохранение фильтра при входе,
переход из очереди, поиск клавишей /, фокус и сохранение адреса при пропуске к содержимому,
окно поиска и меню на 390×844. Горизонтального переполнения страницы и пересечения
окна, панели и плеера нет. Изменения верстки сверены по снимкам экрана.
Перед публикацией сохранены исходники, локальная база и согласованный бекап Neon.

Тесты отката адаптированы к базе с уже существующим журналом: проверяется сохранность
предыдущих решений, а не предположение о нуле правок. Сценарии пустого журнала явно
создают его только в собственной временной копии.
