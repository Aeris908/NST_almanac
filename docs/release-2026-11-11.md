# Исправления интерфейса — 11 ноября 2026

## Изменения

- Безопасный вывод журнала и дельты редактора, текста профиля; встроенный токен кабинета удалён.
- Неизвестный маршрут и повреждённое имя игрока возвращают читателя в рабочий раздел с пояснением.
- Сезон сохраняется в ссылке и после перезагрузки; закрытие профиля возвращает в прежний раздел.
- Профиль поддерживает Escape, удержание и возврат фокуса, блокировку фоновых элементов.
- Каталог по умолчанию сортируется по числу матчей; подпись явно указывает охват «Вся карьера».
  При равном проценте побед сортировка учитывает число матчей; поиск игнорирует крайние пробелы.
- Увеличены мелкие подписи каталога, повышен контраст вторичного текста.
- Аудиоплеер показывает понятные ошибки вместо инструкций по файловой системе, сворачивается,
  запоминает трек и позицию. При обычном переходе между страницами возможна пауза;
  автоматическое продолжение зависит от политики браузера. Полноценный PJAX не заявляется.
- В выпуск входят также проверенные исправления синхронизации, предпросмотра и безопасной
  вставки JSON из предшествующего аудита, а также дизайн-документ.
